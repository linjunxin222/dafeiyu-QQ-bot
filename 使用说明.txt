大肥鱼 QQ 机器人
================

一、启动
双击桌面“大肥鱼 QQ 机器人”。
启动器会同时拉起 Breeze 语音、SoulX 唱歌、AstrBot 和 NapCat；AstrBot 与 NapCat 并行启动，控制台窗口隐藏。
已经加入开机启动：登录 Windows 后会自动启动，重复双击也不会重复启动。
看门狗会清理重复的 NapCat 进程，避免两个实例互相顶号。
热启动约 1–2 秒；冷启动主要等 AstrBot，约 30–40 秒，之后 QQ 和语音会自动就绪。
如果 QQ 登录态失效，它会自动打开扫码页面；只有登录态真的失效时才需要扫码，不要把机器人 QQ 同时登在别的设备上。
也可以双击文件夹里的“启动机器人.bat”，效果相同。

二、后台
后台地址、账号和密码见本文件夹内的“后台.txt”。
后台只监听本机，别的电脑不能直接访问。

三、机器人设置
- 模型：DeepSeek / deepseek-flash
- 长期记忆：本机 Ollama + bge-m3（Ollama 位于 D:\大肥鱼\Ollama）；召回 6 条、保留最近 3 条，反思阈值 8 轮，上下文窗口 70 条；所有记忆保留、不自动衰减/清理，并启用主动记忆工具，重要事情可以明确叫她记住
- 识海：保存在 `D:\大肥鱼\识海` 的自我、主人、时间线、事实和语气；事实带时间、来源、可信度；答应的事会记进未完成清单；每天 04:00 自动去重整理并备份；每轮只注入一小段，不上传
- 识海观察窗：双击桌面“识海观察窗”，会把识海和最近 300 条私聊导出成只读三维记忆海，地址 `http://127.0.0.1:4174`；只监听本机，不改识海、不上传
- 表情包：本地两套梗图 + QQ 原生小黄脸；说“发个调皮”“委屈一下”“来个OK”会发 QQ 原生表情，普通梗图仍会自动配图
- 图片/表情包识别：能看主人发来的图片和表情包，并自然接话；图片最长边已提高到 2048px
- 视频识别：自动抽取最多 6 帧关键画面看内容，不是完整视频
- 生图：本机 ComfyUI + NoobAI-XL，1024px 生成后用 waifu2x 2 倍到 2048px；默认二次元动漫风，负面词过滤线稿/黑白/水印；生图时会暂停 Breeze/SVS 约一分钟，完成后自动恢复；说“画一张……”“给我生一张图”就会画；连续生图有 18 秒冷却；Cloudflare/Pollinations 作为备用，Cloudflare token 当前失效
- QQ 空间：只有主人让她发时才发
- 语音：Breeze TTS 2 本地语音，dafeiyu 音色（标准普通话、十六七岁少女音，更幼更软更奶，甜亮清脆，会气鼓鼓撒娇，委屈带一点哭腔，傲娇嘴硬），约十条回复一条语音；每次整条回复合成一条语音，不会一段一段（启动器会自动拉起 Breeze）
- 唱歌：说“唱首歌”“点歌”“唱个生日歌”，她会现编歌词，用本机 SoulX-Singer 按谱唱；可选《小星星》《两只老虎》《生日快乐》，约 10–30 秒；唱歌服务端口 18620，启动器和看门狗会自动拉起；不花云端费用
- 翻唱：发音频（带伴奏也行，会自动做人声分离并优先用去混响人声；清唱更稳），配一句“翻唱”，默认用本机 RVC 大肥鱼模型跟着原唱的音高/旋律转换，再和原伴奏混音，只做轻 EQ/压缩/响度；RVC 不可用时回退 SoulX-SVC；一次最多 60 秒，大约两三分钟；期间会短暂停掉 Breeze/SVS 省显存，完成后自动恢复；优先发音频文件，QQ 语音可能转码失败
- 找歌：说“找歌 歌名”，先查 `D:\大肥鱼\歌曲库`，再查网络上的歌曲信息；不会自动下载版权歌曲；发音频时写“存歌 歌名”会存进本地库，之后说“唱 歌名”即可直接翻唱
- QQ 接入：NapCat → AstrBot（OneBot v11 WebSocket）
- 使用范围：仅管理员大号私聊
- 群聊和其他 QQ 的消息会被拦截
- 电脑操作能力：已关闭（只开 QQ 表情包、空间、签名等工具，本机执行权限全部关闭）

四、文件说明
AstrBot\        AstrBot 程序、运行环境和配置
NapCat\         NapCat 与 QQ 运行文件
logs\           运行日志
后台.txt        后台地址、账号、密码
deepseek-key.txt  DeepSeek API key（请勿外传）
大号QQ.txt       管理员大号号码（请勿外传）

五、稳定性
- 启动器会同时运行一个后台看门狗，AstrBot 或 NapCat 异常退出会自动拉起来。
- 看门狗日志：logs\watchdog.log
- 启动器日志：logs\launcher.log
- 记忆检索超时已放宽，Ollama 的 bge-m3 会保持加载，减少记忆召回失败。
- 重复双击桌面快捷方式不会重复启动，只会检查状态。
- 连续回复之间至少间隔 1.2 秒，降低 QQ 因短时间连发多条而触发风控/禁言的概率；不要短时间连续发大量图片和语音。

六、注意
1. 不要删除或移动本文件夹内的文件，否则机器人可能无法启动。
2. 不要把“后台.txt”“deepseek-key.txt”“大号QQ.txt”发给别人。
3. 首次启动 AstrBot 需要几秒，等后台提示 WebUI ready 后再用 QQ。
4. 如果 QQ 登录态失效，启动器会自动打开扫码页面；扫完即可。

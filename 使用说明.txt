大肥鱼 QQ 机器人
================

一、启动
双击桌面“大肥鱼 QQ 机器人”。
启动器会在后台启动 AstrBot 和 NapCat，不需要保留控制台窗口。
如果 QQ 登录态失效，它会自动打开扫码页面。

也可以双击文件夹里的“启动机器人.bat”，效果相同。
重复双击不会重复启动，只会检查当前状态。

二、后台
后台地址、账号和密码见本文件夹内的“后台.txt”。
后台只监听本机，别的电脑不能直接访问。

三、机器人设置
- 模型：DeepSeek / deepseek-flash
- 长期记忆：本机 Ollama + bge-m3（Ollama 位于 D:\大肥鱼\Ollama）
- 表情包：已装两套，按情绪自动配图
- 图片/表情包识别：能看主人发来的图片和表情包，并自然接话
- 视频识别：自动抽取最多 6 帧关键画面看内容，不是完整视频
- QQ 空间：只有主人让她发时才发
- 语音：豆包 Seed TTS 2.0，甜美桃子音色，语速稍慢自然、音调稍高，整条回复合成，约三条回复一条语音
- QQ 接入：NapCat → AstrBot（OneBot v11 WebSocket）
- 使用范围：仅管理员大号私聊
- 群聊和其他 QQ 的消息会被拦截
- 电脑操作能力：已关闭（只开 QQ 表情包、空间、签名等工具，本机执行权限全部关闭）

四、文件说明
AstrBot\        AstrBot 程序、运行环境和配置
NapCat\         NapCat 与 QQ 运行文件
logs\           运行日志
后台.txt        后台地址、账号、密码
deepseek-key.txt  DeepSeek API key（请勿外传）
大号QQ.txt       管理员大号号码（请勿外传）

五、稳定性
- 启动器会同时运行一个后台看门狗，AstrBot 或 NapCat 异常退出会自动拉起来。
- 看门狗日志：logs\watchdog.log
- 启动器日志：logs\launcher.log
- 记忆检索超时已放宽，Ollama 的 bge-m3 会保持加载，减少记忆召回失败。
- 重复双击桌面快捷方式不会重复启动，只会检查状态。

六、注意
1. 不要删除或移动本文件夹内的文件，否则机器人可能无法启动。
2. 不要把“后台.txt”“deepseek-key.txt”“大号QQ.txt”发给别人。
3. 首次启动 AstrBot 需要几秒，等后台提示 WebUI ready 后再用 QQ。
4. 如果 QQ 登录态失效，启动器会自动打开扫码页面；扫完即可。
